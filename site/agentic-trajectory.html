    Build: Field Agent

    one project · 18 commits · released on GitHub

    Setup once

    Windows PowerShell · no cloud account needed
    ollama pull qwen2.5:7b
mkdir field-agent ; cd field-agent
python -m venv .venv ; .\.venv\Scripts\Activate.ps1
pip install openai pydantic
git init
    Get Ollama ↗

    Create core.py and a notes/ folder with the three files first. Every step imports them. Then take the steps in order: write the file, run it, try the prompts, commit.

    Release

    after any step, as often as you like
    git add . ; git commit -m "Field Agent: step 04 tools"
gh repo create field-agent --public --source . --push

    Commit after every step. The git history becomes the learning log, and the repository is the thing you release. Tick "ran it" and "committed" below as you go.
