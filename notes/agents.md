# Agents, in short

An AI agent is a language model given tools and knowledge so it can act on an environment, not only answer in text. The loop is perceive, reason, act, repeat.

Agent types from the course: simple reflex, model-based reflex, goal-based, utility-based, learning, hierarchical, and multi-agent systems.

Use an agent when the problem is open-ended, needs several tool steps, or should improve from feedback. Do not use one for a fixed, single-step calculation.
